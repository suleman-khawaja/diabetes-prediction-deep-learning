## 📌 Project Overview
The objective of this project is to build a robust Feedforward Neural Network (FNN) that evaluates tabular health metrics and predicts binary diabetes risk classification (Diabetic vs Non-Diabetic). 

Special technical focus was applied to:
* **Preventing Data Leakage:** Fitting scalers strictly on training data.
* **Biologically Sound Imputation:** Replacing zero values in physiological indicators with median values.
* **Overfitting Mitigation:** Applying L2 regularization ($\lambda = 0.01$) across dense hidden layers.

## 📊 Key Results & Performance Metrics

* **Test Accuracy:** `~81.9%`
* **Test Loss:** `~0.4309`
* **Validation Accuracy:** `~80.0%`
* **Validation Loss:** `~0.4412`

### Real-World Inference Validation:
* **Low-Risk Profile Test:** (Glucose: 130, BMI: 25.5, Age: 28) $\rightarrow$ **~9.24% Probability** (Class 0: Non-Diabetic)
* **High-Risk Profile Test:** (Glucose: 190, BMI: 42.0, Age: 55) $\rightarrow$ **~83.24% Probability** (Class 1: Diabetic)
